# Research attribution

Email Atomizer is an independent Burp extension inspired by Gareth Heyes' PortSwigger Research paper:

- "Splitting the email atom: exploiting parsers to bypass access controls"
  https://portswigger.net/research/splitting-the-email-atom
- Research materials:
  https://github.com/PortSwigger/splitting-the-email-atom

The mutation engine in this project is an independent implementation organized around the paper's
Probe -> Observe -> Encode -> Exploit methodology. It does not vendor PortSwigger's Turbo Intruder
or Hackvertor source code.
